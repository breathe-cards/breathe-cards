# Security policy

Breathe Cards is a front-end card: it runs in the browser, reads the state of the sensor you configure and opens the Home Assistant history dialog when tapped. It makes no network requests and stores no data.

## Reporting a vulnerability

Please report security problems privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue for them.

You will get an answer within a week. Fixes are released as a new version and noted in the [changelog](CHANGELOG.md).

## Supported versions

Only the latest release receives fixes.
